# 가격 조건·제외 상품·후속 안내 변경

2026-11-06 적용.

- `budget.amount`와 `comparison`으로 가격 조건을 표현한다. LTE=이하(기존 요청 기본값), LT=미만, GTE=이상, GT=초과, RANGE=양 끝 포함 범위다. RANGE는 `upper_amount`가 필요하다. `scope`는 기존 PER_UNIT/TOTAL을 유지한다. 새 budget은 기존 가격 조건 전체를 대체한다. Python이 할인 적용 금액과 경계값을 비교하며 화면은 동일 조건으로 표시한다.
- 추천 응답 `data.excluded_products`에는 상품 ID·이름·제외 사유·요청 수량·최대 구매 가능 수량을 제공한다. 가격·옵션 조건까지 충족하지만 재고가 부족한 기종만 포함한다. 경고에도 기종 이름을 표시하고 같은 기종의 SKU는 중복 집계하지 않는다.
- 공통 응답의 선택 필드 `follow_up`은 안내문 `text`와 다음 행동 `options`(label/message)를 담는다. 필수 추가 질문이 있으면 그것을 우선하며 중복 안내하지 않는다. 추천·상세·비교·견적·검색 결과 없음·재고 부족에 상황별 안내를 제공한다. 제안 자체로 조건을 완화하거나 선택을 확정하지 않는다.

검증: 자동 테스트 146개 통과. 실제 Qwen3 8B·DB 상담에서 기존 100만 원 이하 조건을 100만 원 이상으로 대체하고, 추천 5개 모두 100만 원 이상인지 확인했다. Galaxy S26 Ultra 품절 제외 정보와 후속 행동 선택지도 확인했다.
