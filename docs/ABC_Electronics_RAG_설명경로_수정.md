# 제품 설명 RAG 연결 수정

사용자 보고: “갤럭시 S25 장점 알려줘”가 무관한 5개 상품 추천으로 처리됨.

확인 결과: SAM012 문서는 rag.document_chunks에 정상 저장되어 있으며, 문제 질문은 제품 설명 분기로 연결되지 않았다. 추천용 RAG 경로가 존재하는 것만으로 제품 설명 기능이 구현된 것은 아니었다.

수정:
- 내부 의도 KNOWLEDGE 추가. 기종을 명시한 장점·특징·성능 설명을 해당 상품 문서 검색에 연결.
- 확인한 상품 ID 범위, 기존 qwen3-embedding:0.6b, 1024차원, pgvector 코사인 검색 사용.
- 문서의 제품 특징에서 사실 후보를 추출하고 모델이 관련 근거를 선택. 선택 범위를 검증해 외부 사실·가격·재고를 새로 생성하지 않음.
- 응답 data.explanation={product_id,points:[{text,source_ids}]} 추가. 기존 message와 sources로 화면 표시 가능.
- 근거 없음은 NOT_FOUND evidence 상태로 명시하고 무관한 상품 추천으로 대체하지 않음.
- PDF 장단점 표가 두 열 혼합으로 추출된 구간은 안전하게 장단점을 분리할 수 없어 사용하지 않음. 단점 설명 품질은 문서 추출 보완이 필요함.
- 기존 대화 상태의 마지막 견적을 설명 요청 중 지우지 않도록 별도 상태 복사 수정.

실제 검증: “갤럭시 S25 장점 알려줘” → SAM012, Samsung_제품설명서.pdf 12쪽, 벡터 검색 거리 0.2633346633, retrieval_method=vector. 키워드 fallback 사용 없음.

반환 근거: 최대 120Hz 디스플레이, Snapdragon 8 Elite for Galaxy, 50MP/10MP/12MP 후면 카메라, 3배 광학/최대 30배 디지털 줌. 모두 저장된 설명서 문구에서 선택했으며 실제 시판 상품 정보의 외부 검증을 의미하지 않음.

자동 테스트 107개 통과. 실제 모델 통합 재현: `python -m backend.tests.smoke_knowledge` (실행 중인 backend 컨테이너에서 실행).
