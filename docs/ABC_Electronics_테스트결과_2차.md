# ⑥ 테스트 케이스 및 평가 결과 — 2차

날짜: 2026-11-05 / 범위: 추천 API·상품 조회 Tool·설명서 RAG

## 실행 결과

- Docker 빌드 성공, 기존 기능 포함 자동 테스트 57개 통과(실제 DB 읽기 전용 테스트 2개 포함).
- 실제 모델: `qwen2.5:3b`, 임베딩: `qwen3-embedding:0.6b`, pgvector 1024차원.
- 특정 상품 RM-15C + 예산 50만원 + 배터리 용도: HTTP 200, 상품 1개·출처 1개. 최초 모델 로딩 포함 약 24.06초.
- 전체 상품 중 예산 50만원 + 배터리 용도: HTTP 200, 상품 5개·출처 5개, 약 4.99초.
- 시간은 현재 노트북에서의 단회 측정이며 응답시간 보장이 아니다.

## 확인한 조건

| 항목 | 검증 결과 |
|---|---|
| RAM·용량별 가격 | 지정 옵션만으로 최저 판매가 계산 |
| 카드 할인과 예산 | 할인 전 가격으로 미리 탈락시키지 않음 |
| 총예산·개당 예산 | 요청 수량을 반영해 판정 |
| 빈 상품 범위 | 전체 검색으로 풀지 않고 결과 없음 |
| 품절·요청 수량 부족 | 추천에서 제외하고 짧게 안내 |
| 동점 정렬 | 용도 점수 → 3개월 판매량 → 가격 |
| 문서 검색 범위 | 검증된 후보 상품·임베딩 모델·차원으로 제한 |
| 공개 출처 | 문서명·페이지·짧은 발췌 요약, 추천 이유의 ID와 연결 |
| 잘못된 임베딩 | 차원 오류·NaN·영벡터 거부 |
| 잘못된 모델 평가 | 미등록 ID·중복 ID·잘못된 점수 거부 |
| 모델 실패 | 오류 반환, 임의 추천으로 대체하지 않음 |
| 부적절한 입력 | null·범위·중복 용량 조건 등 거부 |

## 남은 평가

추천 적합성 점수와 RAG 거리 0.65는 초기 설정이다. 대표 상담 시나리오에 대한 사람 검토, 모델별 품질 비교, 동시 사용자 부하, 세션·SSE 평가와 전체 신규 PC 초기화 검증은 아직 수행하지 않았다. 내부 비교·판매 순위 Tool의 대화 연결도 다음 단계다.
