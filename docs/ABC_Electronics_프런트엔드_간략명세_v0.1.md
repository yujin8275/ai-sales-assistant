# ABC Electronics 고객 프런트엔드 간략 명세

버전 0.1 / 2026-11-05 / 구현 전 초안

| 화면 | 필수 내용 |
|---|---|
| 메인 `/` | ABC Electronics 로고, 연한 파랑 배너, AI 상담 시작 버튼, DB 기반 상품 카드, 우측 하단 챗봇 진입 버튼. 예시의 광고·금액 대신 확인된 데이터 사용 |
| 상담 `/chat` | 좌측 확정 조건·선택 상품, 우측 대화·최대 5개 추천 카드·옵션 표·견적 카드, 하단 입력창, 새 상담 버튼 |
| 추천 카드 | 상품 이미지·기종·“판매가 ○○원부터”·해당 RAM/용량/색상·재고·추천 이유·문서 출처 요약. 상품 선택 시 판매 옵션 조회 |
| 옵션·견적 | 전체 색상과 RAM별 SKU·판매가·재고 표. 선택은 채팅 문장으로 전송. 견적에는 수량·할인 전 금액·카드 할인·총액·조회 기준 표시 |
| 상태 | SSE로 조회·계산 중 표시. 검증 완료 결과만 화면에 반영. 추가 질문은 선택지+직접 입력, 오류는 재요청 안내, 30분 만료·새 상담 시 초기화 |
| 반응형 | PC는 좌측 패널과 대화 영역, 모바일은 조건 패널 접기와 카드 세로 배치. 긴 대화에서도 입력창 유지 |

**동작:** `/sessions`로 상담 ID 발급 → `/chat`으로 문장 전송 → SSE를 읽어 카드·표 렌더링. 선택지 클릭도 `message`로 전송한다. 새 상담은 reset API를 사용한다. 고객 화면은 대화 내용을 임의 분석해 확정 조건을 만들지 않는다.

**추가 API 계약:** 좌측 패널을 위해 채팅 final의 `data.consultation`에 서버가 확정한 `constraints`, `selected_items`, `expires_at` 요약을 추가한다. 기존 API 명세에는 해당 객체가 없어 구현 전에 동기화해야 한다. 직접 API는 상담 상태를 변경하지 않는다.

**기술 제안:** 고객 화면은 React·TypeScript·Vite를 우선 제안하며 최종 선택 대기다. 기존 Streamlit은 관리자 승인 적재 화면으로 유지한다. 고객 화면과 API는 같은 주소의 `/api` 경로로 연결해 PC별 API 주소 수정이 없게 한다.

**첫 버전 범위:** 메인·상담·추천·옵션·견적. 주문·결제·배송·장바구니·실제 상담원 연결은 제외한다. 근거 없는 “ABC카드 5%”, 무료배송, 출고 보장, 고객센터 연락처를 복사하지 않는다. 홈의 인기 정보는 등록된 최근 3개월 판매 데이터와 기준일로 표시한다. 채팅 내 최대 5개와 홈 상품 진열은 구분하되 별도 전체 카탈로그·검색 기능은 후순위다.
